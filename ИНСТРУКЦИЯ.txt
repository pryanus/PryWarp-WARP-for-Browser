======================================================================
  PryWarp — WARP for Browser  |  Короткая инструкция
======================================================================

ТРЕБОВАНИЕ:
  На Windows должен быть установлен Python 3.10+ (https://www.python.org/downloads/
  или в терминале: winget install Python.Python.3.12).
  При установке поставь галочку "Add Python to PATH".

----------------------------------------------------------------------
1. КАК ПОДКЛЮЧИТЬ (2 ШАГА)
----------------------------------------------------------------------

ШАГ 1 — Запусти фоновый мост:
  Дважды нажми на файл:  УСТАНОВИТЬ_МОСТ.cmd
  Мост тихо запустится в фоне и пропишется только в автозагрузку
  текущего пользователя Windows (без прав администратора и без VPN-драйвера).

ШАГ 2 — Добавь расширение в браузер (выбери папку под свой браузер):
  • Папка extension-chromium (движок Chromium):
    Подходит для: Google Chrome, Яндекс Браузер, Microsoft Edge,
    Opera, Opera GX, Brave, Vivaldi, Atom, Arc.
    1. Открой  chrome://extensions  (в Яндексе: browser://extensions,
       в Edge: edge://extensions, в Opera: opera://extensions)
    2. Включи "Режим разработчика" (переключатель вверху)
    3. Нажми "Загрузить распакованное расширение"
    4. Выбери папку:  extension-chromium
    (В Brave работают обычные вкладки; приватное окно с Tor изолировано.)

  • Папка extension-firefox (движок Firefox / Gecko):
    Подходит для: Mozilla Firefox, Tor Browser, Zen Browser,
    LibreWolf, Waterfox, Floorp.
    1. Открой  about:debugging#/runtime/this-firefox
    2. Нажми "Загрузить временное дополнение..."
    3. Выбери файл manifest.json внутри папки:  extension-firefox
    (В Tor Browser работает до перезапуска; для не-WARP сайтов в
     настройках расширения есть совместимость с цепочкой Tor.)

Закрепи значок PryWarp на панели браузера:
  • Зелёные очки  = WARP активен и мост на связи
  • Красные очки  = защита выключена в попапе или мост не запущен

----------------------------------------------------------------------
2. КАК УДАЛИТЬ МОСТ
----------------------------------------------------------------------

  1. Дважды нажми на файл:  УДАЛИТЬ_МОСТ.cmd
     (остановит процесс и уберёт автозагрузку из реестра)
  2. Удали расширение из браузера и при желании саму папку PryWarp.

----------------------------------------------------------------------
3. КАК ЭТО РАБОТАЕТ И НА ЧТО ВЛИЯЕТ
----------------------------------------------------------------------

  • Внутри используется открытый клиент Cloudflare WARP MASQUE:
    https://github.com/Diniboy1123/usque  (бинарник bridge\usque.exe).
  • Мост поднимает локальный SOCKS5-прокси (127.0.0.1:10880) и API
    статуса (127.0.0.1:10881) строго в user-space.
  • Системный VPN-адаптер НЕ создаётся. Windows Proxy, DNS, hosts,
    игры и отдельные программы (включая настольный Discord.exe) НЕ меняются.
  • Без включённого расширения в браузере трафик вообще не идёт в WARP.
  • При первом запуске usque сам регистрирует бесплатный WARP-ключ в
    локальный файл bridge\config.json (только на твоём ПК).
  • 1 добавленный домен автоматически покрывает и корень, и все
    поддомены (*.domain). Кнопка "Ко всем сайтам" переключает режим
    обхода на весь внешний трафик браузера (кроме localhost и LAN).

----------------------------------------------------------------------
4. ЕСЛИ ОДНОВРЕМЕННО РАБОТАЕТ ZAPRET-DISCORD-YOUTUBE (winws.exe)
----------------------------------------------------------------------

  По умолчанию zapret содержит cloudflareclient.com в list-general.txt
  и мешает туннелю usque (растёт задержка, мост падает в HTTP/2).
  Добавь исключения в папку lists\ от zapret и перезапусти его:
    • В list-exclude-user.txt:
        cloudflareclient.com
        consumer-masque.cloudflareclient.com
    • В ipset-exclude-user.txt:
        162.159.198.0/24
